# v0.19.5 release and upgrade notes

[中文说明](v0.19.5.zh-CN.md)

## Changes since v0.19.4

This maintenance release refreshes the first-party kit dependencies and their compatible transitive requirements. The HTTP kit moves from v2.0.2 to v2.1.0; APT Proxy retains the existing retry API. Regression coverage checks request replay and cancellation, 4xx/5xx handling, Range requests, and private/shared cache isolation and invalidation. The release gate runs the real package-manager client matrix before publication.

Go remains 1.27.3. Repository routes, configuration keys, cache formats and CLI interfaces are unchanged. Documentation entry points and historical dependency acknowledgments have also been clarified.

## Upgrade

Pin the new image or replace the binary from the release archives:

```sh
docker pull soulteary/apt-proxy:v0.19.5
# Equivalent registry:
docker pull ghcr.io/soulteary/apt-proxy:v0.19.5
```

Retain your configuration and persistent cache volume. No configuration or cache migration is required from v0.19.4. Check health/readiness and perform a package metadata refresh and a repeated package download through the proxy before switching all clients. For older installations, review the [v0.19.4 notes](v0.19.4.md) and their linked earlier migration requirements.

If rollback is necessary, restore the previous binary or v0.19.4 image with the same configuration and cache volume. Do not remove persistent caches as part of a routine upgrade.
