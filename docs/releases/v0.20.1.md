# apt-proxy v0.20.1

Release date: 2026-11-26 (Asia/Shanghai)

## Dependencies

- `github.com/soulteary/health-kit/v4`: `v4.0.9` → `v4.0.10`.
- `github.com/soulteary/metrics-kit/v3`: `v3.0.7` → `v3.0.8`.
- `github.com/soulteary/middleware-kit/v3`: `v3.0.7` → `v3.0.8`.
- `github.com/soulteary/logger-kit/v3`: `v3.0.7` → `v3.0.8`.
- `github.com/soulteary/version-kit/v4`: `v4.0.6` → `v4.0.7`.

## Compatibility and upgrade

The proxy continues to use net/http. Configuration keys and cache/snapshot formats are unchanged by this dependency refresh. Go remains 1.27.4. middleware-kit v3.0.8 includes the Fiber rate-limit key ownership fix; request-buffer reuse no longer changes retained limiter keys. This does not change the net/http adapter API.

Retain the previous program/image and back up configuration before deployment. No cache or snapshot-format migration is introduced. Verify the configured package-manager families, cache reuse and upstream-failure behavior. To roll back a source build, restore the complete previous go.mod and go.sum and rebuild.

This release also includes dependency, container and workflow maintenance already merged since v0.20.0; exact runtime requirements are recorded in go.mod/go.sum. Redis-backed services retain their existing go-redis v9.24.0 requirements from main; review retry, timeout and pool settings when upgrading from an older published deployment.

Full changes: https://github.com/soulteary/apt-proxy/compare/v0.20.0...v0.20.1

When upgrading from a release older than v0.20.0, also follow the [v0.20.0 upgrade notes](https://github.com/soulteary/apt-proxy/blob/v0.20.1/docs/releases/v0.20.0.md) for the earlier redirect, routing and mirror-default changes.
