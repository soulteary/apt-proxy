# v0.19.5 发布与升级说明

[English](v0.19.5.md)

## 相比 v0.19.4 的变化

本次维护版本更新第一方 kit 依赖及其兼容的间接依赖。HTTP kit 从 v2.0.2 升到 v2.1.0，APT Proxy 继续使用原有重试 API。回归覆盖请求重放与取消、4xx/5xx、Range 请求、私有与共享缓存的隔离和失效；发布门禁在产物发布前运行真实包管理器客户端矩阵。

Go 仍为 1.27.3，仓库路由、配置字段、缓存格式和命令行接口保持兼容。同时整理了文档入口与历史依赖致谢。

## 升级

更新镜像标签或使用 Release 中的二进制替换：

```sh
docker pull soulteary/apt-proxy:v0.19.5
# 也可使用：
docker pull ghcr.io/soulteary/apt-proxy:v0.19.5
```

保留现有配置与持久化缓存卷。从 v0.19.4 升级无需迁移配置或缓存。切换全部客户端前，检查健康与就绪接口，通过代理刷新包索引并重复下载一个软件包。更旧版本请先阅读 [v0.19.4 升级说明](v0.19.4.zh-CN.md)及其链接的迁移要求。

如需回滚，恢复旧二进制或 v0.19.4 镜像，沿用现有配置与缓存卷。常规升级不需要删除持久化缓存。
