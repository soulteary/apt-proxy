# v0.19.4 发布与升级说明

[APT Proxy v0.19.4](https://github.com/soulteary/apt-proxy/releases/tag/v0.19.4)

[English notes](v0.19.4.md)

## 相比 v0.19.3 的变化

- **补充 Proxmox 配置示例。** [#174](https://github.com/soulteary/apt-proxy/pull/174)
  在 [`config/distributions.yaml`](../../config/distributions.yaml) 中增加默认注释的
  PVE、PBS Server、PBS Client 和 Ceph Squid 条目，不会自动启用新路由或改变有效默认配置。
- **整体语句覆盖率门槛提高到 95%。** [#175](https://github.com/soulteary/apt-proxy/pull/175)
  补充配置优先级、仓库快照、Metalink、缓存隔离、存储故障、资源准入和服务生命周期测试。
  发布报告记录的整体语句覆盖率为 96.32%。95% 门槛针对 `./...` 的总量，不代表每个包
  或分支覆盖率。内部拆分了命令执行函数和监听/重载循环，公开命令与信号接口保持不变。
- **依赖维护。** [#173](https://github.com/soulteary/apt-proxy/pull/173)
  将 health-kit 更新至 v4.0.4、middleware-kit 更新至 v3.0.3，Go 版本仍为 1.27.3。

## 升级

替换二进制，或固定使用新镜像标签：

```sh
docker pull soulteary/apt-proxy:v0.19.4
# 也可使用 GHCR：
docker pull ghcr.io/soulteary/apt-proxy:v0.19.4
```

从 v0.19.3 升级无需迁移配置。已有自定义 `distributions.yaml` 不会被覆盖或自动扩展。
需要 Proxmox 示例时，将所需条目取消注释后加入有效的 `distributions` 列表，确保自定义
类型不冲突，再重载发行版配置。具体配置与仓库范围见 [PBS Client 示例](../../examples/proxmox/)。

从 v0.19.2 或更早版本升级时，请注意：v0.19.3 修复了镜像根地址缺少尾部斜杠时的
URL 拼接，避免生成 `/debian/pbs-clientdists/...` 一类地址。v0.19.2 增加了域名与路径
联合匹配优先级，以及严格的发行版 YAML 字段校验，请阅读其[升级说明](v0.19.2.zh-CN.md)，
尤其注意 `cache_control` 的拼写。修复前缓存的错误仓库元数据可能还需要清理代理缓存并刷新
客户端索引；升级不会改写已缓存的响应。

## 验证与发布产物

[发布工作流](https://github.com/soulteary/apt-proxy/actions/runs/40728681270)
在发布前通过全部 18 个 Linux AMD64 真实客户端、汇总证据检查、带 race 检查的 Go
测试及 95% 覆盖率门槛。本地签名仓库验证了安装和缓存复用，不代表每个公共镜像或客户端
CPU 架构都已验证，范围见[客户端支持说明](../client-support.md)。

本次提供 Linux/macOS 二进制归档、Linux `.deb`/`.rpm`/`.apk` 安装包、归档 SBOM 和
`checksums.txt`。Docker Hub 与 GHCR 提供 `linux/amd64`、`linux/arm64`、`linux/arm/v7`
多架构镜像。ARMv6 提供二进制归档和 Linux 安装包，未提供容器镜像。
